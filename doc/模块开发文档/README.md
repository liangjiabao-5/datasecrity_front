## 文档维护规则

本目录的强制归档规则以项目根目录 [AGENTS.md](../../AGENTS.md) 为准。后续 AI 在完成模块开发、修复或交接说明时，必须将文档写入上表对应的模块目录；跨模块内容写入 `跨模块联动`，不得重新散落到 `doc/` 根目录。

除同一需求需要持续补充外，每次独立变更使用一个新文件，文件名为 `YYYY-MM-DD-简要主题.md`。例如：`2026-08-04-风险清单批量导入校验.md`。
