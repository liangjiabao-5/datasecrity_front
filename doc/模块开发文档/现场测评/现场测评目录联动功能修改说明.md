# 现场测评目录联动功能修改说明

更新时间：2026-05-29

## 修改范围

- 页面：现场测评
- 文件：
  - `src/views/workflow/EvaluationView.vue`
  - `src/types/evaluation.ts`
  - `src/api/evaluationApi.ts`
  - `src/mock/workflowDb.ts`

## 删除的功能

1. 删除前端对现场测评独立目录接口结果的依赖。
   - 前端不再使用 `GET /api/v1/projects/{projectId}/evaluation/catalog` 的结果渲染左侧“检查项目录”。
   - 左侧目录改为直接根据检查项列表数据生成，避免目录与表格数据不一致。

2. 删除左侧目录点击后按旧字段 `categoryId` 过滤表格的逻辑。
   - 新目录筛选维度改为 `sheet_name` 和 `category`。

## 修改的功能

1. 左侧“检查项目录”改为两级目录。
   - 一级目录：检查项数据中的 `sheet_name` 字段。
   - 二级目录：检查项数据中的 `category` 字段。

2. 目录与表格联动。
   - 点击一级目录时，表格筛选当前 `sheet_name` 下的全部检查项。
   - 点击二级目录时，表格筛选当前 `sheet_name + category` 下的检查项。
   - 点击“重置”时，清空关键字、评估结果和目录筛选。
   - 目录数据按分页拉取本项目全部检查项后生成，避免只根据当前表格页或单次接口返回数据生成不完整目录。

3. 表格“分类”列展示字段调整。
   - 原展示：`categoryName`。
   - 新展示：`subcategory`。
   - 为兼容旧数据，前端兜底展示顺序为 `subcategory`、`subcategoryName`、`categoryName`、`category`。

4. 检查项查询参数扩展。
   - 前端调用检查项列表时会透传 `sheet_name`、`sheetName`、`category`。
   - 当前前端仍保留本地兜底筛选，后端暂未支持这些参数时，页面联动仍可工作。

5. 风险类型选项和回显调整。
   - 编辑弹窗风险类型改为原型中的固定风险类型选项。
   - 现场测评列表风险类型回显统一转为中文名称。
   - 前端兼容旧风险类型编码、原型中的短编码和中文名称，保存时统一为稳定编码。

## 后端需配合项

1. `GET /api/v1/projects/{projectId}/evaluation/items` 返回的每条检查项建议补充：
   - `sheet_name`：用于左侧一级目录。
   - `category`：用于左侧二级目录和目录筛选。
   - `subcategory`：用于表格“分类”列展示。

2. 检查项列表接口建议支持以下筛选参数：
   - `sheet_name`
   - `category`

3. `GET /api/v1/projects/{projectId}/evaluation/catalog` 如后续无其他页面使用，可考虑废弃或保留为兼容接口。

4. 风险类型字段 `riskTypes` 建议后端统一存储稳定编码，并在接口文档中补充以下选项：
   - `DATA_LEAKAGE`：数据泄露风险
   - `DATA_TAMPERING`：数据篡改风险
   - `DATA_DESTRUCTION`：数据破坏风险
   - `DATA_LOSS`：数据丢失风险
   - `DATA_ABUSE`：数据滥用风险
   - `DATA_FORGERY`：数据伪造风险
   - `ILLEGAL_OBTAIN_DATA`：违法违规获取数据
   - `ILLEGAL_SELL_DATA`：违法违规出售数据
   - `ILLEGAL_SAVE_DATA`：违法违规保存数据
   - `ILLEGAL_USE_DATA`：违法违规利用数据
   - `ILLEGAL_PROVIDE_DATA`：违法违规提供数据
   - `ILLEGAL_DISCLOSE_DATA`：违法违规公开数据
   - `ILLEGAL_BUY_DATA`：违法违规购买数据
   - `ILLEGAL_EXPORT_DATA`：违法违规出境数据
   - `OVER_SCOPE_PROCESSING`：超范围处理数据
   - `LACK_PROCESSING_JUSTIFICATION`：数据处理缺乏正当性
   - `NO_PERSONAL_RIGHTS_PROTECTION`：未有效保障个人信息主体权利
   - `APP_ILLEGAL_PERSONAL_INFO_COLLECTION`：App违法违规收集使用个人信息
   - `LACK_PROCESSING_FAIRNESS`：数据处理缺乏公平公正
   - `PROCESSING_REPUDIATION_RISK`：数据处理抵赖风险
   - `DATA_UNCONTROLLABLE_RISK`：数据不可控风险
   - `DATA_INFERENCE_RISK`：数据推断风险
   - `OTHER_RISK`：其他风险
