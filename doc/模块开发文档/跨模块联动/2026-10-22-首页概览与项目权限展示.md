# 首页、项目管理与鉴权 - 首页概览与项目权限展示

日期：2026-10-22  
类型：功能开发 / 联调记录 / 执行记录

## 背景与目标

新增参考蓝紫渐变横幅、彩色统计卡和白色圆角项目卡的首页，展示当前用户可见的最近创建项目。首页作为登录默认入口，保留既有项目管理与评估启动流程；项目数据和统计都由后端按当前用户权限过滤。

## 实际执行内容

1. 新增 `/dashboard`，根路径、正常登录及已登录访问登录页时进入首页；带合法站内目标路径的登录仍回到原目标，拒绝 `//` 开头地址及登录页自身。
2. 侧栏增加首页导航。公共顶部只在当前路由项目 ID 与缓存项目匹配时显示项目名，首页不显示旧项目。
3. 新增四项统计：全部项目、待开始、进行中、已完成；统计包含全部可见项目，不局限首页 6 条。“全部项目”明确包含已归档项目。
4. 点击统计卡进入 `/projects?status=...`。项目管理初始化并监听状态参数，支持状态切换、返回导航、重置和第一页刷新；不支持的值及重复参数数组按全部处理。
5. 最近项目请求第一页、每页 6 条，沿用后端创建时间倒序。卡片显示名称、编号、状态、评估单位、所有者、访问身份、创建时间；长文本支持原生悬停提示，缺失值显示“—”。后端无时区 ISO 时间按 UTC 解释后显示北京时间。
6. 待开始项目通过共用只读详情弹窗查看，其他状态进入基本信息。报告入口进入项目报告管理。首页不调用开始评估、删除或编辑接口；创建入口受 `project:create` 控制。
7. 进入、窗口恢复可见/获得焦点和手动刷新时，先同步 `/auth/me`，再并发加载列表与统计。合并同一会话的并发刷新，卸载移除监听；无定时轮询或推送。
8. 刷新清除旧展示；无读取权限、零项目、权限同步失败、列表失败、统计失败分别处理。失败统计显示“—”，允许局部成功并提供重试；任一数据接口明确拒绝权限时丢弃两部分结果。
9. 增加会话与请求版本保护：退出、会话失效或切换主体时清理项目缓存；迟到的列表、详情、权限同步、首次登录恢复、HTTP 响应及 Token 自动刷新不能恢复旧账号数据或覆盖新账号凭证。正常 Token 刷新仍共享刷新请求并自动重试。
10. Mock 列表同步按创建时间倒序，编辑 Mock 项目时保留原创建时间；Mock 仅用于本地视觉核验。
11. 根据首页浏览器批注，将横幅“数据安全风险评估”从 12px 调整为 16px、字重 600，保持主标题层级。

## 影响范围

- 页面/组件：新增 `src/views/DashboardView.vue`、`src/components/project/ProjectDetailDialog.vue`；调整布局、项目管理和登录页。
- 数据与状态：新增首页加载协调器、展示工具，调整鉴权及项目 store、HTTP 会话版本保护。
- 接口：复用 `GET /api/v1/auth/me`、`GET /api/v1/projects?pageNo=1&pageSize=6`、`GET /api/v1/projects/statistics` 和既有项目详情/配置接口；无新增接口、业务字段、数据库迁移或权限代码。
- 关联模块：项目管理、报告入口、登录鉴权；后端仅新增回归测试，没有修改业务实现。

## 使用或联调说明

1. 生产和真实联调必须使用 `VITE_USE_MOCK=false`、后端 `AUTH_REQUIRED=true`。已核对当前前端开发/生产配置及后端本地配置满足要求；示例配置不能替代实际部署配置。
2. 普通用户需同时具备 `project:read` 和所有者/有效协作关系；超级管理员可见全部未逻辑删除项目。前端不提交用户 ID 决定可见范围，不获取全量项目再自行过滤。
3. 协作授权撤销后，后端在下一次请求时拒绝访问；首页重新进入、切回窗口或手动刷新后移除卡片。本期不承诺静置页面立即获知撤权。
4. 待开始项目仍需从项目管理点击“开始评估”生成测评项快照；首页查看详情不会生成快照或变更状态。
5. 本次构建写入独立验证目录，未覆盖仓库中开发前已有的 `dist` 改动；未部署、未提交 Git、未写入真实业务数据。
