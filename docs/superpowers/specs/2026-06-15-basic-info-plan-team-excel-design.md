# 基本信息与评估团队 Excel 导入导出设计

## 背景

项目基本信息页当前提供 JSON 本地导入导出，页面包含“项目基本情况”和“被评估单位基本信息”两个标签页，其中被评估单位页还包含联系人信息明细表。

评估方案页当前提供 JSON 本地导入导出，页面包含“评估团队”“被评估方团队”“关注点”“差距项”四个标签页。本次只覆盖用户点名的“评估团队”和“被评估方团队”两个团队标签页，不调整关注点和差距项的导入导出范围。

现场测评页已经采用后端 Excel 文件接口模式：导出模板、导入、导出。为了保持一致，本次也按后端生成与解析 Excel 的方式设计。

## 功能范围

项目基本信息页新增“导出模板”按钮，并将导入、导出切换为 Excel 文件能力：

- 导出模板：下载空模板或包含当前项目基础辅助数据的模板。
- 导入：上传 Excel 后，由后端解析并返回结构化数据，前端自动填充页面表单；用户仍需点击“保存”让当前表单正式生效。
- 导出：下载当前项目基本信息 Excel，文件内容来自后端持久化数据。

评估方案页新增“导出模板”按钮，并将团队相关导入、导出切换为 Excel 文件能力：

- 导出模板：下载包含“评估团队”和“被评估方团队”两个 sheet 的模板。
- 导入：上传 Excel 后，由后端解析并写入两个团队列表，前端刷新团队数据；关注点和差距项不受影响。
- 导出：下载当前项目的两个团队列表 Excel。

## Excel 结构

项目基本信息 Excel 包含 3 个 sheet：

- `项目基本情况`：项目编号、项目名称、评估所依据的法律法规、评估所参考的标准规范、评估开始日期、评估结束日期。
- `被评估单位基本信息`：单位名称、邮政编码。
- `联系人信息`：姓名、所属部门、移动电话、职务/职称、办公电话、电子邮件。

评估方案团队 Excel 包含 2 个 sheet：

- `评估团队`：姓名、单位、角色。
- `被评估方团队`：公司/部门、姓名、职位、联系方式。

## 前端设计

新增文件下载工具函数，复用 Axios 的 blob 能力，支持从响应头解析文件名，解析不到时使用默认文件名。

新增基本信息和评估方案团队导入结果归一化工具，兼容后端直接返回业务对象或 `{ code, data }` 解包后的对象。项目基本信息导入结果映射为现有 `BasicInfoPayload`；评估方案团队导入结果映射为 `assessmentTeam` 和 `clientTeam` 两个数组。

`basicInfoApi` 新增：

- `exportTemplate(projectId)`
- `exportFile(projectId)`
- `importExcel(projectId, file)`

`planApi` 新增：

- `exportTeamTemplate(projectId)`
- `exportTeamFile(projectId)`
- `importTeams(projectId, file)`

页面交互保持当前操作区布局，只在导入上传组件的 `accept` 中支持 `.xlsx,.xls`，导出模板和导出均通过文件下载工具保存到本地。

## 错误处理

导入接口失败时，页面展示“导入失败：原因”。后端如返回行级错误明细，前端本次先展示总错误信息，后续可按现场测评页面的异常明细弹窗扩展。

项目基本信息导入后只填充当前页面状态，并提示“请保存后生效”；评估方案团队导入后以后端写入结果为准，刷新两个团队列表并提示导入成功。

## 验证

新增脚本测试覆盖：

- 基本信息导入结果归一化：字段缺失时补默认值，引用条目和联系人数组保持数组结构。
- 评估方案团队导入结果归一化：只提取评估团队和被评估方团队，不要求关注点和差距项。

执行验证命令：

- `node scripts/basicInfoExcelImportResult.test.mjs`
- `node scripts/planTeamExcelImportResult.test.mjs`
- `npm run typecheck`
- `npm run build`
